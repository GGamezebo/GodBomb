# Овертайм на вылет

Основное время партии — колода из `account.game_time_minutes` (`GameSession`). После последнего взрыва основного времени:

1. Уникальный минимум штрафов → сразу окно результатов.
2. Несколько игроков с одинаковым минимумом → овертайм на вылет.
3. Туториал не входит в овертайм: пустая колода → `MATCH_END`.

## Овертайм

- Сплеш: основное время истекло, продолжают только с минимумом штрафов, остальные выбывают (`eliminated_at = 0`).
- Кнопка состава (add/remove/swap) скрыта до конца матча.
- Колода добирается случайными слогами, пока не останется один активный.
- Полоску «до конца партии» не показывать.
- Каждый взрыв: +1 штраф и игрок выбывает (`eliminated_at = 1, 2, …`). Сплеш «игрок выбывает».
- Если активных ≥ 2 → следующий раунд. Если остался один → сплеш, затем результаты.

## Лидерборд

Сортировка: `score` ASC, затем `eliminated_at` DESC. Не выбывший (`eliminated_at = -1`) считается последним и стоит выше при равных штрафах.

Пример: 1 / 1 / 1 / 3 → в овертайм трое с 1. Взрывы A→2, B→2, C=1 победитель. Рейтинг: C, B, A, игрок с 3.

## Код

- `GamePlayer.is_active`, `eliminated_at`
- `GameSession.is_overtime`, `enter_overtime()`, `eliminate_player()`, `active_count()`, `next_player()` только по активным
- Тай-брейк «одна лишняя карта» в `next_card()` убран
- После взрыва FSM остаётся в `explosion`, пока сплеш не закроется (~3.5 с / тап), затем `EXPLOSION_DONE` или `MATCH_END`
- Сплеш: `GameEvents.ev_battle_splash` → `BattleSplashOverlay`
- Emergency в овертайме: выбирать только `is_active`
