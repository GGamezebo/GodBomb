# RuStore

**Консоль:** https://console.rustore.ru/apps/2063768470 (Android, бесплатно). На 2026-10-15 приложение «Не опубликовано», версий нет; вход через VK ID, консоль местами отдаёт «временно недоступна».

**Статус (2026-10-15):** версия `1.0.4 (5)` отправлена на модерацию (публикация автоматическая, аудитория 100%); предыдущая `1.0.3 (4)` из списка версий исчезла (заменена, вероятно в архиве). Не заполнено: видео (только VK Видео), «Запрашиваемые данные» (пусто — игра ничего не собирает).

**Preset:** `RuStore APK` (preset.4) → `bin/android/tictacbadaboom_rustore.apk`, feature `rustore` (**без** `play`). Копия `Android APK`, отличается только именем, features и путём. Нет feature `play` → `NullBackend` в `PlatformServices` и `godbomb_android` не добавляет gradle-зависимость `play:review` (на устройствах без GMS Play-код не нужен). Пакет тот же `com.tictacbadaboom.app`, `version/code` ведётся отдельно от Play.

**Подпись:** keystore для пресета вводится в окне Export (хранится в `.godot/export_credentials.cfg`, у каждого пресета свой). Ключ после первой публикации менять нельзя — решить заранее: тот же upload key, что в Play, или отдельный; либо отдать подпись RuStore («Подпись приложения»).

**Материалы и тексты:** `docs/store/rustore_draft.md`. Политика конфиденциальности — как у Play (itch).

**Не делает ассистент:** вход в консоль, верификация разработчика, отправка на модерацию — только пользователь.
